# Linux Labs
this folder contains my linux practice exercise, hands-on labss and command-line activities completed during my cybersecurity learning journey.
## Skills Practiced 
### Linux Navigation & File Management
Navigate directories using ~cd~
Displayed current directory with 'pwd'
Listed files and hidden files using 'ls' and 'ls -a'
Viewed file content using 'cat', 'head' and 'tail'
Created and edited files using 'nano'
Used 'echo' and 'expr'
### Searching & Filtering
Used 'find' to locate files and directories
Used 'grep' for searching and filtering text
Practice piping and filterung commands
### Permissions & Ownership
Displayed file permission using 'chmod'
Changed file ownership using 'chown'
Granted elevated privileges using 'sudo'
### User & System management
Modified existing user accounts using 'usermod'
Installed and removed applications using the APT package manager
Used 'whatis' and 'apropos' to research linux commands

Linux Terminal
Ubuntu (WSL)
Nano Text Editor
